\section{¿Qué es modelo MVC?}

El modelo MVC (Modelo-Vista-Controlador) es una forma de organizar el código de un programa separándolo en tres partes: el modelo, la vista y el controlador. Esta división ayuda a que el trabajo sea más ordenado, fácil de entender y de corregir.

\section{Modelo}

El modelo define la estructura de datos y actualiza la vista de la aplicación.

\section{Vista}

La vista define la interfaz de usuario.

\section{Controlador}
